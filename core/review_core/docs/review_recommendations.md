# v0.3 额外修改建议清单

以下建议暂未全部落为强规则，建议继续通过回测决定。

## 1. A类不强制采访原话（已确认）

已修改：
- A类稿件不再要求必须出现采访原话；
- 证据标准改为“核心证据充分性”；
- 具体数字、操作细节、官方原始文件、现场观察、直接采访等均可构成直接证据；
- 重点判断证据能否支撑核心判断，而不是机械检查证据格式。

## 2. Topic Gate 与 Evidence Gate 的边界继续收紧

Topic 只应判断：
- 这个题有没有现实获取证据的可能；
- 是否值得投入调研。

Evidence 才判断：
- 现在拿到的证据够不够；
- 来源是否可靠；
- 能否支撑当前结论。

避免完整成稿因为没显示引用格式而被 Topic 提前打回。

## 3. 不建议新增“战略归因真实性”独立 BLOCKER

多个动作被作者归纳成统一战略，本身就是评论分析的重要价值。
更合理的控制方式已经由 `I005 判断克制度` 覆盖：
- 有直接证据，可以强判断；
- 只有事实拼图，就用“呈现出、可以理解为、看起来更像”等分析性措辞；
- 重点检查证据与措辞强度是否匹配。

## 4. “MAJOR >= 3 自动 REVISE”可能过于机械

三个轻微表达问题和一个严重逻辑问题不是同一件事。
建议后续改为：
- MAJOR 分“逻辑型 / 证据型 / 表达型”；
- 只有逻辑型、证据型累计达到阈值才阻塞；
- 纯表达型 MAJOR 不应因为数量机械触发 REVISE。

## 5. 区分“文章有主线”与“所有案例必须归入一个理论框架”

系统应鼓励清晰主线，但不应把现实强行整理成唯一解释。
评价重点：
- 案例是否服务核心问题；
- 推导是否自然；
- 是否出现作者为了框架完整而强行给事实贴标签。

## 6. E类与C类的最终审核应更独立

未来建议 Final Gate 不再仅做统一汇总，而是为 C/E 建立专属终审模板：
- C重点：口径、准确转译、决策含义；
- E重点：时效、完整、结构清晰、可检索性。
这样能进一步降低深度稿标准误伤其他内容类型的概率。

## 7. 目前最重要的不是继续加规则，而是继续回测

建议至少完成：
- A类 5篇
- B类 5篇
- C类 3篇
- D类 3篇
- E类 3篇

每篇记录：
- False Pass
- False Reject
- Wrong Diagnosis
- Over-constraint（规则过严）
- Under-constraint（规则过松）

达到约20篇后，再冻结 v1.0。
