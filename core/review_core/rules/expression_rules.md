# 表达规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、判断句要机制

### X001｜判断句不靠模板

**Stage**
EXPRESSION

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
判断句是否由具体机制支撑，而非靠固定转折句式制造深刻感？

**通过条件**
机制清楚，句式自由。

**失败条件**
只换模板句式，没有新增机制。

**例外**
- 无


## 二、抽象词汇

### X002｜抽象判断必须被具体证据兑现

**Stage**
EXPRESSION

**适用类型**
A / B / C / D / E

**严重级别**
MAJOR

**判定问题**
抽象概括是否在同段或紧邻上下文被案例、数字、场景或具体主体兑现？

**通过条件**
抽象词背后有可核查内容。

**失败条件**
连续抽象概括，无具体支撑。

**例外**
- 不设置词汇黑名单。
- 不要求机械地恰好下一句举例。


## 三、具体名词与抽象名词比例

### X003｜核心判断避免纯抽象名词堆叠

**Stage**
EXPRESSION

**适用类型**
A / B / C / D / E

**严重级别**
MAJOR

**判定问题**
核心判断句中是否有具体主体、动作、项目或场景？

**通过条件**
至少能定位具体主体或动作。

**失败条件**
结构、生态、价值、维度等抽象名词连续堆叠。

**例外**
- 无


## 三、碎片化与长句

### X004｜避免碎片化煽动

**Stage**
EXPRESSION

**适用类型**
A / B / C / D / E

**严重级别**
MAJOR

**判定问题**
是否连续三段以上每段仅一句且以问号结尾？

**通过条件**
没有通过密集碎片问句制造情绪。

**失败条件**
连续三段以上符合该特征。

**例外**
- 无

### X005｜过度学术化长句

**Stage**
EXPRESSION

**适用类型**
A / B / C / D / E

**严重级别**
MINOR

**判定问题**
是否存在超过60字且多层连接词嵌套的长句？

**通过条件**
信息层级清晰。

**失败条件**
句子过长导致逻辑负担。

**例外**
- 无


## 四、叙事与信息融合

### X006｜独立信息框风险

**Stage**
EXPRESSION

**适用类型**
A / B / C / D

**严重级别**
MINOR

**判定问题**
背景资料是否用TIPS/项目符号等独立信息框割裂叙事？

**通过条件**
核心信息被编织进连续叙事。

**失败条件**
重要判断被放进容易跳过的信息框。

**例外**
- 若信息框承载核心判断，严重度升级为MAJOR。
