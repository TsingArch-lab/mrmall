# 结构规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、底层逻辑链

### S001｜A/B完整论证闭环

**Stage**
STRUCTURE

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
文章是否完成设问→证据→推导→收束判断，并且正文的主要章节真的在推进解释，而不只是给若干能力标签分别挂上正向案例？

**通过条件**
核心问题、具体证据、必要推导和判断形成可理解的闭环。多个案例可以全部是正向案例，但主要章节至少应通过机制解释、案例差异、决策过程、条件关系或递进关系推进核心判断；读者读完能够说清“为什么这些材料共同支持这个判断”，而不仅是记住企业做了很多事、取得很多成绩。

**失败条件**
缺少核心问题、证据、推导或收束判断中的任一关键环节；或文章虽然形式上有“观点小标题+案例+总结句”，但主要结构实际是“能力标签A→若干成功案例→再次确认A；能力标签B→若干成功案例→再次确认B”。如果段落之间主要累加品牌、项目、活动、首店、销售、客流等正向材料，而没有继续拆出选择标准、作用机制、案例差异或关键决策，仍属于清单式论证。

**例外**
- 反证不再作为每篇文章的固定结构要求。
- 商业合作稿允许使用较多正向案例，也不要求每一章都设置反面材料；关键只看这些案例是否承担真实的分析功能。
- 个别段落用于补充成绩或背景不构成FAIL，只有当这种写法成为正文主要论证方式时才触发。

## 三、反证空间

### S004｜反证内容按需进入正文

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
MINOR

**判定问题**
正文是否省略了一个已经明显存在、且足以误导读者理解核心结论边界的重要局限？

**通过条件**
一般情况下N/A。文章不需要专门设置反面章节；只要核心判断没有因为省略重大边界而产生实质误导，就视为通过。

**失败条件**
文章材料本身已经显示某个关键局限/风险会改变核心结论，但正文完全略去，导致读者被引向明显过度的判断。

**例外**
- 不要求固定反面段落。
- 不要求为了形式上的客观而面面俱到。
- 不要求失败案例。
- 普通的适用边界、尚待观察或“可能还有其他原因”不构成FAIL。

**通过条件**

**失败条件**
为凑结构强行拆成三段，案例可互换。

**判定问题**

## 六、论证推进

### S007｜论证推进与功能增量

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
正文各主要段落或章节相对于前文，是否持续增加“有效论证增量”，使读者对核心问题的理解发生推进，而不是只增加新的文字、案例、数字或抽象说法？

**通过条件**
主要段落或章节承担新的论证功能，使读者对核心问题的理解至少发生一种实质变化：获得新的关键事实；理解新的机制或因果环节；增加成立条件、适用边界或反例；形成有区分度的新比较；把已有判断继续推到新的经营结果或决策含义；将分散事实第一次归纳成此前尚未明确的关系；或完成不可缺少的承上启下。

“有新信息”本身不等于“有有效增量”。新增一个案例、一组数字、几个品牌、一个抽象概念或一次同义改写，只有在它改变、扩展、限定或继续推进读者对核心问题的理解时，才算新的论证功能。多个段落即使各自包含局部新信息，只要它们持续承担同一个已经充分完成的证明功能，仍属于低推进。

**失败条件**
正文存在明显、连续且占据实质篇幅的低推进内容。典型情形包括：一个判断已经得到充分解释后，后续多段只是换案例、换数据或换措辞继续证明同一件事；事实和机制已经讲清后，又反复用“生态、体系、能力、长期主义”等更抽象的概念重新概括，却没有建立新的关系或推论；连续案例各有细节差异，但对核心论证承担完全相同的功能；铺陈大量背景、数据或案例，后续核心判断并不依赖这些材料；或新增内容本身成立，却偏离核心问题。

判断重点不是“这一段有没有任何新东西”，而是“这一段是否让核心理解真正往前走”。可用删除测试和案例边际价值测试辅助判断：若删除一个段落或一组同质段落后，读者对核心问题的理解几乎无损；或无法清楚回答“相比前文，这一段/这一案例多解释、限定或推进了什么”，则属于低功能增量。

**例外**
- 不要求每句话都提供全新事实；必要的短总结、转场、回扣可以存在。
- 有效归纳不属于重复：如果总结第一次把前文分散事实组织成新的机制、关系或判断，应视为推进。
- 同一主题可以持续深入；只要新增内容改变、扩展、限定或推进了核心理解，就不属于原地重复。
- 个别一句或一小段轻微重复不触发 FAIL；只有低推进内容明显、连续并对阅读效率造成实质影响时才触发。
