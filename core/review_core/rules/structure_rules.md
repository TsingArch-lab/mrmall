# 结构规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、底层逻辑链

### S001｜A/B完整论证闭环

**Stage**
STRUCTURE

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
文章是否完成设问→证据→推导→收束判断？

**通过条件**
核心问题、证据、推导和判断形成完整闭环；反例/风险/替代解释仅按I006条件触发。

**失败条件**
缺少核心问题、证据、推导或收束判断中的任一关键环节。

**例外**
- 反证不再作为每篇文章的固定结构要求。


## 三、反证空间

### S004｜反证内容按需进入正文

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
当前核心判断是否触发了反例/风险/替代解释检查，且这些内容是否有必要进入正文才能避免误导？

**通过条件**
未触发则N/A；触发后，仅在其会实质改变读者对结论边界的理解时写入正文。

**失败条件**
存在明显会改变结论边界的重要局限，却完全省略，导致正文结论显得过度确定。

**例外**
- 不要求固定反面段落。
- 不要求为了形式上的客观而面面俱到。


## 四、排比小标题检验

### S005｜小标题关系真实

**Stage**
STRUCTURE

**适用类型**
A / B / C / D / E

**严重级别**
MAJOR

**判定问题**
小标题是并列还是递进？对应的打乱/跳跃测试是否通过？

**通过条件**
并列边界清晰；递进中间环节不可随意删除。

**失败条件**
为凑结构强行拆成三段，案例可互换。

**例外**
- 无


## 五、去尾测试

### S006｜正文先于抒情收尾立住

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
BLOCKER

**判定问题**
删除最后1-2段抒情收尾后，正文是否仍能独立完成核心任务？

**通过条件**
正文已经立住判断/解释/立场。

**失败条件**
结尾承担了本应由正文完成的论证。

**例外**
- 类型E以信息任务完成为准。
