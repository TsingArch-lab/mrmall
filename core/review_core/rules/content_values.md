## 四、真实永远优先于精彩

### G001｜真实性优先

**Stage**
GLOBAL

**适用类型**
A / B / C / D / E

**严重级别**
BLOCKER

**判定问题**
关键事实与结论是否来自可核查材料，而非模型补齐、猜测或未经标注的推断？

**通过条件**
所有关键事实均可追溯；推断明确标注；证据不足时降低确定性或留白。

**失败条件**
存在无法追溯却以事实口吻呈现的关键内容。

**例外**
- 无


## 五、好的判断从具体事实里长出来

### G002｜事实先于判断

**Stage**
GLOBAL

**适用类型**
A / B / C / D / E

**严重级别**
BLOCKER

**判定问题**
核心判断能否追溯到具体事实、数据、引语、操作细节或明确的项目决策过程？

**通过条件**
核心判断至少有一条清晰的“事实→推导→判断”链条。商业内容不要求对每个判断完成学术式证明或排除所有替代解释；第一方经营数据、采访和项目操作细节可以作为有效证据，但其证明范围不得被无依据扩大。

**失败条件**
先有观点，再用零散案例或成绩清单装饰；或大量罗列品牌、活动、销售、客流等结果，却没有解释这些事实如何支持核心判断。

**例外**
- 类型D允许个人立场，但必须明确区分事实与个人判断。
- 第一方材料本身不构成失败；只有当它被直接当作“企业很成功/能力很强”的自我证明，且缺少具体事实与推导时，才构成问题。

## 四、真实永远优先于精彩

### I005｜判断确定性不得超过证据强度

**Stage**
INSIGHT

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
核心或关键判断的措辞强度，是否明显高于文章现有事实链能够合理支持的程度？

**通过条件**
只要具体事实、案例和决策过程能够形成合理推导，就允许作者作出有力度的商业判断，不要求排除所有其他解释。局部修辞略强、带有评论性或传播性的表达，不因不够“学术严谨”而自动失败。

**失败条件**
文章从有限事实直接跳到决定性、唯一性、普遍性结论，且这个跳跃会实质改变读者对核心判断的理解；例如仅凭一个结果就断言某能力必然成立、某模式普遍有效。

**例外**
- 若核心机制有连续的具体动作、结果或多处材料支撑，可以使用较强判断。
- “领先、成功、最重要、唯一”等强词需要与文章核心证据相匹配，但个别宣传性措辞不应自动阻塞全文。
- 仅存在其他可能解释，不等于当前判断失败。

## 四、真实优先于精彩

### I006｜反例与替代解释条件触发

**Stage**
INSIGHT

**适用类型**
A / B / C / D

**严重级别**
MINOR

**判定问题**
是否存在一个明确且有现实依据的替代解释/风险，足以让当前核心判断发生实质变化？

**通过条件**
没有这样的强替代解释时N/A。普通商业案例不要求为了完整性主动寻找失败案例；有合理证据链即可形成判断。

**失败条件**
存在文章材料本身已经暴露、或常识上非常直接的重要替代解释/风险，若纳入会显著改变核心判断，但文章完全跳过。

**例外**
- 不要求为了形式完整加入反面段落。
- 不要求证明当前解释是唯一解释。
- 不要求第三方反证。
- “还可能有别的原因”这种抽象可能性不能触发FAIL。

## 四、真实永远优先于精彩

### F003｜终审判断克制度

**Stage**
FINAL

**适用类型**
A / B / C / D / E

**严重级别**
BLOCKER

**判定问题**
全文最终的核心判断，是否存在一个没有现有证据链就无法成立的重大跳跃？

**通过条件**
正文已完成“事实→推导→判断”的基本闭环。允许有评论性、有力度的商业判断，也允许证据并非学术意义上的排他证明；只要核心结论能被现有材料合理解释即可。

**失败条件**
核心结论主要靠口号、企业自评、成绩清单或未经推导的因果/普遍化跳跃成立；一旦拿掉这一步跳跃，全文核心判断就明显无法成立。

**例外**
- 局部措辞偏满、单个句子略强、反证讨论不充分，不单独触发F003 BLOCKER，应由I005/E003/I006/S004按对应级别处理。
- 不要求每篇文章完成第三方验证或排除所有替代解释。
