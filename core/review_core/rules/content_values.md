## 四、真实永远优先于精彩

### G001｜真实性优先

**Stage**
GLOBAL

**适用类型**
A / B / C / D / E

**严重级别**
BLOCKER

**判定问题**
关键事实与结论是否来自可核查材料，而非模型补齐、猜测或未经标注的推断？

**通过条件**
所有关键事实均可追溯；推断明确标注；证据不足时降低确定性或留白。

**失败条件**
存在无法追溯却以事实口吻呈现的关键内容。

**例外**
- 无


## 五、好的判断从具体事实里长出来

### G002｜事实先于判断

**Stage**
GLOBAL

**适用类型**
A / B / C / D / E

**严重级别**
BLOCKER

**判定问题**
核心判断能否追溯到具体事实、数据、引语或操作细节？

**通过条件**
核心判断至少有一条清晰证据链。

**失败条件**
先有观点，再用零散案例装饰；或判断无法指出来源。

**例外**
- 类型D允许个人立场，但必须明确区分事实与个人判断。

## 四、真实永远优先于精彩

### I005｜判断确定性不得超过证据强度

**Stage**
INSIGHT

**适用类型**
A / B / C / D

**严重级别**
BLOCKER

**判定问题**
当前措辞的确定性，是否高于现有证据能够支持的程度？

**通过条件**
事实、推断、作者判断被清楚区分；相关性不被写成未经证明的因果；局部案例不被无依据外推为普遍规律。

**失败条件**
证据只支持‘可能/呈现出/倾向于’，文章却写成‘就是/决定了/证明了/必然导致’。

**例外**
- 若有直接证据、充分时间链或高度一致的多源事实支撑，可使用更强判断。


## 四、真实优先于精彩

### I006｜反例与替代解释条件触发

**Stage**
INSIGHT

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
当前判断是否触发了需要额外检查反例/风险/替代解释的条件？

**通过条件**
未触发则N/A；触发后，作者已检查相关反例/局限/替代解释，并据此校准判断强度。

**失败条件**
触发条件明显存在，却完全未检查，且当前结论因此显得过度确定。

**例外**
- 不要求为了形式完整而加入固定反面段落。
