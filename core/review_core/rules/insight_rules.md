# 观点生成规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、普通观点 vs 高级观点

### I001｜核心判断包含具体机制

**Stage**
INSIGHT

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
如果同行追问‘为什么’，能否回答出具体X如何导致Y？

**通过条件**
判断包含明确机制链条，不只是结果或形容词。

**失败条件**
专业、成功、年轻化、长期主义等抽象标签替代机制。

**例外**
- 无


## 一、高级观点三个特征

### I002｜高级观点至少满足2项

**Stage**
INSIGHT

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
观点是否具备可证伪、可执行、有归因链条中的至少两项？

**通过条件**
至少2项成立。这里的‘可证伪’指现实中存在明确检验边界，不要求文章主动提供反方案例。

**失败条件**
只有描述性归纳或态度判断。

**例外**
- 不得把‘可证伪’解释为‘必须在正文中自我反驳’。


## 二、五个追问

### I003｜五个追问均已过一遍

**Stage**
INSIGHT

**适用类型**
A / B

**严重级别**
MAJOR

**判定问题**
比较、话语拆解、多案例、历史、数据五个追问是否都被检查过？

**通过条件**
五问均有回答或明确记录无有效结果。

**失败条件**
只沿着作者最初思路单线推进。

**例外**
- 无


## 三、失败模式1

### I004｜判断不能只是事实改写

**Stage**
INSIGHT

**适用类型**
A / B / C / D

**严重级别**
BLOCKER

**判定问题**
核心判断是否只是把前文事实换一组抽象词重新说一遍？

**通过条件**
判断对事实进行了机制解释、关系解释或决策解释。

**失败条件**
事实→同义概括，没有信息增量。

**例外**
- 类型E不适用。
