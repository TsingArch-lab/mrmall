# 开头写法规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、开头唯一目标 + 四、隐性设问

### S002｜开头制造具体认知缺口

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
BLOCKER

**判定问题**
读完前三句话，读者能否明确复述‘接下来想知道什么’？

**通过条件**
形成具体阅读期待；可以显式提问，也可以隐含在场景/反差中。

**失败条件**
只有背景介绍，没有阅读驱动力。

**例外**
- 不要求问号。
- 类型E可豁免深层设问。


## 三、开头到正文的转场

### S003｜开头必须有落点句

**Stage**
STRUCTURE

**适用类型**
A / B / C / D

**严重级别**
MAJOR

**判定问题**
开头的场景/历史/体验是否被一句落点连接到正文主体？

**通过条件**
存在明确转场，不让开头空转。

**失败条件**
故事讲完后突然跳到正文。

**例外**
- 无
