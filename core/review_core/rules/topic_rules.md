# 选题判断规则

> 本文件是人工维护的 Rule Source of Truth。Registry、Gate、Agent、Feedback 均不得反向修改本文件。


## 一、问题1 深层问题

### T001｜深层问题

**Stage**
TOPIC

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
连续追问三次‘这说明了什么’后，是否已经超越事实复述和行业常识？

**通过条件**
第三层问题形成可验证、值得分析的经营或行业问题。

**失败条件**
仍停留在‘企业做得不错/符合趋势/消费者喜欢’。

**例外**
- 无


## 一、问题2 判断链条可迁移

### T002｜判断层可迁移

**Stage**
TOPIC

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
抽掉具体主体名称后，核心判断是否仍然是关于行业或经营机制的判断？

**通过条件**
判断可脱离单一企业成立，同时证据保持主体专属性。

**失败条件**
判断只是对该企业的描述，换主体即失效。

**例外**
- 无


## 一、问题3 经营决策落点

### T003｜经营决策落点

**Stage**
TOPIC

**适用类型**
A / B / C

**严重级别**
BLOCKER

**判定问题**
能否自然补全‘因此，一个招商/运营/项目总，可以据此判断或调整___’？

**通过条件**
能形成具体动作、判断标准或决策含义。

**失败条件**
只能说‘值得关注/很有意思/体现趋势’。

**例外**
- 类型D不强制。
- 类型E不强制。


## 一、问题4 值得追问的矛盾

### T004｜真实张力

**Stage**
TOPIC

**适用类型**
A / B / D

**严重级别**
MAJOR

**判定问题**
是否存在反常识、反预期、行业共识冲突、代价或此前赌注中的至少一项？

**通过条件**
至少存在一项真实张力，并能被证据支持。

**失败条件**
只能通过修辞制造冲突。

**例外**
- 类型E不要求。
- 类型C可由数据异常或口径差异替代。


## 一、问题5 一手证据

### T005｜核心证据可得

**Stage**
TOPIC

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
是否有现实路径获得具体数字、原话或操作细节？

**通过条件**
存在可获得的具体数字、原话、操作细节、现场观察或原始文件，能够支撑文章展开分析。第一方经营数据和直接采访可作为有效核心证据。

**失败条件**
只能获得抽象PR话术、成绩清单或二手概括，无法还原任何具体动作、决策过程或经营事实。

**例外**
- 类型C以权威原始公开文件为核心证据。
- 类型E以权威、及时、完整的信息源为核心证据。

## 四、调研止损标准

### E001｜A类核心证据充分性

**Stage**
EVIDENCE

**适用类型**
A

**严重级别**
BLOCKER

**判定问题**
是否存在足够具体、可追溯的直接证据支撑核心判断？

**通过条件**
至少具备具体数字、操作细节、官方原始文件、现场观察、直接采访等证据中的两类，或虽不足两类但单一证据来源足够具体、连续，能够支撑核心判断的主要推导。

**失败条件**
核心判断主要依赖抽象描述、PR口号、成绩罗列或不可追溯的二手概括，无法形成“事实→推导→判断”的链条。

**例外**
- 不强制要求必须存在采访原话。
- 不要求每个事实都由独立第三方验证。项目方提供的具体经营数据、决策过程和操作细节可以作为直接证据。
- 若某类证据缺失，但其他直接证据已经足够支撑核心判断，不构成FAIL。

## 一、问题5 一手证据

### E002｜PR不可自证

**Stage**
EVIDENCE

**适用类型**
A / B

**严重级别**
BLOCKER

**判定问题**
核心判断是否把企业自己的评价性表述或成绩罗列，直接当成了成功与能力的证明？

**通过条件**
企业一手材料可以作为证据；只要正文进一步使用具体数据、动作、决策过程或案例关系完成推导，就不属于“自证”。不要求为了成立而额外寻找独立第三方背书。

**失败条件**
核心判断主要依赖“我们专业/成功/领先/有能力”等企业自我评价，或把销售、客流、首店、奖项等成绩简单罗列后直接推出“能力强/模式成功”，中间缺少实质推导。

**例外**
- 项目方提供的客流、销售、租金、招商、改造收益等具体经营数据，不因来源于项目方而自动失效。
- 只有当第一方材料超出其可证明范围，被直接用于证明更高阶能力或普遍规律时，才触发本规则。

## 四、调研止损标准第3条

### E003｜反向验证意识

**Stage**
EVIDENCE

**适用类型**
A / B

**严重级别**
MINOR

**判定问题**
当前核心判断是否存在会实质改变结论的明显风险、反例或替代解释，而正文完全没有意识到？

**通过条件**
一般性的成功案例、经营复盘和机制分析不要求额外配置失败案例或第三方反证。只有当存在与核心结论直接冲突、足以改变结论的明显信息时，才需要进一步检查或降低判断强度。

**失败条件**
存在显而易见、且会直接动摇核心结论的反例、风险、证据冲突或替代解释，文章却完全忽略，并因此把结论写得明显过满。

**例外**
- 不要求每篇文章必须找到失败案例。
- 不要求独立第三方验证每个经营判断。
- 不要求把所有反向验证结果写进正文。
- 仅仅“还可以有别的解释”不构成FAIL；替代解释必须足以实质改变核心结论。

**Stage**

BLOCKER
